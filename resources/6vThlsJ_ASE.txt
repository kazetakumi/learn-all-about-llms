Let's start with the encoder part of the

Here we convert the input text into

There are different types of

These vectors exist in a highdimensional
space where words with similar meanings

This helps the model understand how
words relate to each other in meaning.
Now that we have word representations,

embedding vector alone doesn't contain

the same size of 512 dimension and is
not trainable. It is generated using s
and cosine functions. Here what it does
for each token position. It computes a
vector using a formula. In this vector,
the even positions use the sign function

function and are computed using the
formula where it takes the position of
each token in the sequence and also the
position of the dimension in the vector.
Like this, we compute the new vector for
all other tokens as well. This helps the
model understand the position of each
word in the sequence. These values are
fixed. They're computed once and stored
in memory, then reused during training.
Even though more recent models use
trainable position encodings, this
static method still performs quite well
and was used by the authors in the
original transformer paper. So now we
have our input sentence represented with
the token embeddings that give the
meaning of words and positional
encodings that provide the word order.
This combined input is then passed into
the first layer of the encoder block.
The first step in the encoder is the
multi head attention layer. But before

works, let's first understand why we

What we have now is a token represented
in this highdimensional embedding space

the words. But here the problem same
words can have different meanings based

does is only capture the semantic
meaning and does not consider the

close to other words related to

its context words deposited and money.
So what we want is to transform this
representation so that it correctly
represents the token by looking at its
context. And for this we have the
attention mechanism. It transforms the
static embedding which only captures the
semantic meaning into the representation
that is aligned with the context. The
size remains the same just the vectors
are now represented according to the
context. In the paper they call this
self attention and it is represented by
this equation. Let's break it down to
understand what it means. First let's
see how we get this query key and value
that you see in the attention
calculation. We take our static
embeddings and linearly transform this
embedding with weight matrices for query
key and value. What this means is take
our embedding as input and use this in
three different neural networks with
linear activations. What this gives is a
query key and value which we use in our
attention calculation. These weights are
trainable layers and so the query key
and value vectors are adjusted after
training. Now that we have our query key
and value matrices, what we do is take
the query and transpose of the key
matrix and then perform matrix
multiplication.
What this does is allow all the tokens
to communicate with all other tokens in
parallel by taking the dotproduct
between the first query vector and the
key vector. It gives a score on how much
it scores to itself. The query acts like
asking all other tokens and giving a
score to each of them on how much they
match. Similarly, it does this with all
other tokens using the key matrix. By
doing this, the first token in our
sequence attends to all other tokens
including itself and has a score that
tells how much it matches with other
tokens. Now, similarly, the second token
in our sequence does the same by taking
its query vector and asking all other
tokens using the key vector. Like this,
all tokens attend to each other using
the query and key in order to know the
importance of other tokens in the
context to make a new representation.
This is done in terms of matrix
multiplication all at once and the
result we get is what we call the
attention score. Since the attention
scores are just scalar values, they can
be a varying range and are not
interpretable. So we first scale these
scores by dividing by the square root of
the dimension of the key vector. We
apply a softmax function to this scaled
attention score across each row which
gives us more interpretable values. So
now each row sums to one and we can
interpret the attention scores in terms
of probability values. We call this
attention weights. If we look at our
token money and look at its attention
weight, then we can interpret it as it
is giving 25% importance to the word
deposited, 30% to money and 30% to the
token bank. Like this in the attention
weight, we now know which token is
important in creating a new
representation.
Using this attention weight and
multiplying with the value matrix, we
get the new representation that has the
context information. So for the word
money, it uses that weight value to act
as a weighted sum to construct a new
embedding which has context
representation.
Like this, a new representation based on
this attention weight is calculated. And
this is what the attention mechanism is
about. Transforming the static embedding
into an embedding that has the context
representation.
So the summary is take the static
embedding with position encoding and
then transform it in three different
matrices called query key and value
matrices using their respective weight
matrices. Then multiply the query and
key scale it and apply softmax to get
the attention weights and multiply this

contextual embeddings.
Now let's see what multi head attention

This is what a single attention head

Since each attention head has output in

weight matrix W out to get the final

This is what happens in multi head
attention. It takes in the static
embedding and gives us new contextaware

heads. This completes the multi head

Now next we have the feed forward neural

After this what we have is the output of

Let's move on to the decoder part and
see what it does. We already have our

Then we have the embedding layer with

As in the encoder's multi head attention

This gives us the attention score for

You can see the first token attends to

Similarly all the tokens are attending

We add this matrix to our original

during attention calculation, the

second token only the token itself and
the tokens before it receive attention.
In this way we can prevent tokens from
attending to future tokens. So in masked

add the mask matrix then scale apply
softmax and multiply with the value
matrix as in the encoder to get the
final embedding. We take multiple
identical self attention and then

another output projection matrix to get

This is what masked multi head attention

normalization after the attention layer

Now after the masked multi head

During training we have the source

single start of sentence token becomes

calculation we use this token since we

one token attends to other tokens from

the decoder. Then all other processes

distribution. We take the last token
probability value to sample because we
already have our second token and want

get that end of sequence token, we stop

sequence and end of sequence tokens. In

But during inference, we generate one
